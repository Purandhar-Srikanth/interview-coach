# Interview Coach (live demo)

An AI mock interviewer for data science / ML roles: it tailors questions to a job description
and resume, scores each answer against a rubric, and remembers your weak areas.

This Space is deployed automatically from the GitHub repository. The demo has a small free
allowance per visitor per day.
